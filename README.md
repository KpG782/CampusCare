# 📱 CampusCare

CampusCare is a mobile application developed using **Flutter** and **FlutterFlow** to support mental health and guidance counseling services for students at the University of Makati. Built with a user-friendly interface and integrated with Firebase, CampusCare empowers students to book counseling sessions, track their moods, and access self-help resources—all in one app.

---

## 🚀 Getting Started

> ⚠️ **Note:** CampusCare is built using the **Flutter _stable_ channel**. Please ensure you're using the latest stable version of Flutter.
